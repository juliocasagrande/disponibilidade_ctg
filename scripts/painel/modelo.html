Configuração de Usinas SIN (Base de Cálculo)

TEIFa · Forçada
TEIFa = Σ[ P · (HDF + HEDF) ] / Σ[ P · (HDF + HEDF + HS + HDCE + HRD) ]

Janela móvel de 60 meses, ponderada pela potência efetiva P.

TEIP · Programada
TEIP = Σ[ P · (HDP + HEDP) ] / Σ[ P · HP ]

Paradas programadas do plano plurianual entram em HDP.

ID & FID (MRA)
ID = (1 − TEIFa) × (1 − TEIP)  |  FID = min(1, ID / ID_ref)
